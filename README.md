# 📊 Superstore Business Intelligence Dashboard

Interactive **Business Intelligence dashboard** built with **Python,
Streamlit, Pandas, and Plotly** to analyze sales performance using the
**Global Superstore dataset**.

The dashboard allows users to explore key business metrics and answer
important analytical questions through interactive filters and
visualizations.

------------------------------------------------------------------------

# 🚀 Project Overview

This project demonstrates how to build an **interactive BI dashboard**
using Python to analyze retail sales data.

The application allows users to explore:

-   geographic sales performance
-   product profitability
-   customer segmentation
-   shipping behavior
-   discount impact on profit

The dashboard is fully interactive thanks to **Streamlit sidebar
filters**, allowing dynamic exploration of the dataset.

------------------------------------------------------------------------

# 📊 Business Questions Answered

The dashboard helps answer the following business questions:

### 1️⃣ Which markets and regions generate the most sales and profit?

Visualizations:

-   **Sales by Market**
-   **Top Countries by Sales**

These charts help identify the most profitable geographic areas.

------------------------------------------------------------------------

### 2️⃣ Which product categories or sub-categories perform best?

Visualizations:

-   **Sales by Category**
-   **Top 10 Sub-Categories by Profit**

This helps identify the most valuable product segments.

------------------------------------------------------------------------

### 3️⃣ How do discounts impact profitability?

Visualization:

-   **Discount vs Profit Scatter Plot**

This chart highlights how higher discounts can reduce profitability
across product categories.

------------------------------------------------------------------------

### 4️⃣ What shipping modes and priorities are most commonly used?

Visualizations:

-   **Shipping Mode Usage**
-   **Order Priority Distribution**

This helps analyze operational and logistics patterns.

------------------------------------------------------------------------

### 5️⃣ Which customer segments contribute the most revenue?

Visualization:

-   **Revenue by Customer Segment**

This helps identify the most valuable customer groups.

------------------------------------------------------------------------

# ⚙️ Features

### 📌 Interactive Filters

Users can filter the entire dashboard using the sidebar:

-   Market
-   Country
-   Category
-   Customer Segment
-   Shipping Mode

All visualizations update dynamically based on selected filters.

------------------------------------------------------------------------

### 📉 Discount Analysis Filter

The **Discount Impact on Profitability** chart includes a separate
filter allowing users to select which product categories to visualize.

This enables easier comparison between:

-   Office Supplies
-   Furniture
-   Technology

------------------------------------------------------------------------

### 📊 KPI Overview

At the top of the dashboard, key metrics are displayed:

-   Total Sales
-   Total Profit
-   Average Discount
-   Total Orders

These KPIs update dynamically based on selected filters.

# ▶️ How to Run the Project

### 1️⃣ Clone the repository

    git clone https://github.com/yourusername/superstore-bi-dashboard.git

### 2️⃣ Install dependencies

    pip install streamlit pandas plotly

### 3️⃣ Run the application

    streamlit run app2.py

The dashboard will open automatically in your browser.
